# Fitting Vlach Landing

Vytvoř moderní single-page landing page pro značku Fitting Vlach v češtině.
Použij přiložený obrázek jako hlavní vizuální referenci stylu a layoutu.

Požadavky:

 světlý, čistý, prémiový design

 typografie má být technická, jednoduchá a velmi dobře čitelná

 vizuální styl: golf, fitting, data, technologie, ale stále lidský a prémiový

 zachovat strukturu landing page:

 hero sekce

 sekce o odbornosti / autoritě

 3 karty pro různé typy klientů

 Deep Fitting sekce s accordionem

 FAQ

 závěrečná CTA sekce

 primární CTA: Domluvit osobní konzultaci

 používat jemné zlaté / olivové akcenty

 hodně whitespace

 sekce mají působit elegantně a profesionálně

 stránka musí být responzivní pro desktop i mobil

 vytvoř komponenty jako:

 navbar

 hero

 cards

 accordion

 FAQ

 CTA footer

 obsah v češtině

 značka v hlavičce: Fitting Vlach

 logo vlevo nahoře: FV

Důležité:

 nechci e-shopový vzhled

 nechci tmavé pozadí

 nechci přeplácaný marketingový styl

 chci čistý, důvěryhodný, technicky působící web
